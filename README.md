# Python Programs Explanation

## Armstrong Number
An **Armstrong Number** is a number where the sum of its digits raised to the power of total digits is equal to the original number.  
Example: `153 = 1³ + 5³ + 3³`

---

## Factorial
A **Factorial** of a number is the product of all positive numbers from 1 up to that number.  
Example: `5! = 5 × 4 × 3 × 2 × 1 = 120`

---

## Fibonacci Series
The **Fibonacci Series** is a sequence where each number is the sum of the previous two numbers.  
Example: `0, 1, 1, 2, 3, 5, 8...`

---

## Histogram
A **Histogram** is a graphical representation using symbols like `*` to visually display values.

---

## Inheritance
**Inheritance** is an Object-Oriented Programming (OOP) concept where one class acquires the properties and methods of another class.
